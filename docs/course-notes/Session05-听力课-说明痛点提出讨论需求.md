## 一、上周作业回顾（Project 第四阶段描述）

### 难点：预期结果 → 用将来时

最后一个阶段是 **Expected key results**（预期结果），属于未来事件，必须用**将来时**。

**示例**：
- *Moving forward, we are expecting to reduce cross-team data transfer times from 48hr to 12hr.*
- *And we will work on saving 70% time per return case.*

**要点**：
- Timeline markers：`Moving forward` / `Looking ahead`
- 主谓宾：`We will work on + doing something`
- 主系表：`We are expecting to + 动词原形`

## 二、听力核心目标

- 学会**通过比喻和证据支撑**识别说话人的 **main idea（观点/claim）**
- 听懂用户反馈、痛点描述
- 理解需求澄清、询问、解释的说法

---

## 三、Claim 与 Support 的关系

| 概念 | 含义 |
|------|------|
| **Claim** | 说话人的立场、观点 |
| **Support** | 支撑观点的理由、证据 |

**结构**：
- 结构 1：Claim → Support（a, b...）→ Claim（paraphrase）
- 结构 2：Support → Claim

> ⚠️ **Support 可能在 Claim 前也可能在后**，答案出现顺序不固定，需听标志词。

## 四、技能一：比喻强化（Metaphorical Framing）

### 句型与标志词

| 句型/表达 | 含义 |
|----------|------|
| **A is like B** / **Doing A is like doing B** | A 就像是 B（本课重点） |
| A is similar to B | A 类似于 B |
| It feels like + 从句 | 感觉就像…… |
| It's as if + 从句 | 好像…… |
| Think of A as B | 把 A 想像成 B |
| Imagine doing B | 想象一下…… |
| A is no different from B | A 和 B 没什么区别 |

### 听力材料中的比喻

| 原文 | 含义 |
|------|------|
| *Using our dashboard is like reading a mystery novel where the middle fifty pages have been ripped out.* | 中间信息缺失，只看到开头和结尾 |
| *You know how it starts and how it ends, but the journey is a total blank.* | 知道开始和结束，中间过程完全是空白 |
| *It's like trying to build a high-speed train while we're still delivering mail on bicycles.* | 目标远大，但基础还很落后 |
| *We have all the ingredients for the soup, but the kitchen is a mess and the guests are already leaving the table.* | 有素材，但系统混乱，用户已在流失 |

## 五、技能二：证据支持（Evidence-Based Justification）

### 什么是证据

- ✅ 具体案例、数据、真实发生的事实
- ❌ 主观感受（如 "This has been a total nightmare"）

### 证据类型与标志词

| 类型 | 标志词 | 示例 |
|------|--------|------|
| **举例 (Examples)** | `To give you an idea of` + 名词（= for example） | *To give you an idea of the data we're dealing with, yesterday a vendor sent me...* |
| **真实案例 (Real Cases)** | `Yesterday` / `Last week` / `One vendor sent...` / `Just the other day` | *Yesterday, a vendor sent me a tracking update that was literally just a photo of a handwritten note.* |
| **后果 (Consequences)** | `Unless we..., ...` / `If we don't..., ...` / `Otherwise...` | *Unless we automate the data standards first, any map we build will just be a fancy way of showing "Information Not Found."* |
| **数据 (Data)** | `X% of users...` / `There were X complaints...` | *15% of users canceled orders...* / *19% of merchant support tickets...* |

### 重要说明

> `Unless we [action], we will [bad outcome]` 中，**Unless we 后面往往就是说话人的 main idea/建议**。

## 六、功能句归类

| 功能 | 标志句 |
|------|--------|
| **表达观点 (Claim)** | `What I'm saying is that...` |
| **比喻 (Metaphor)** | `It's like...` / `A is like B` |
| **举例 (Example)** | `To give you an idea of...` |
| **真实案例 (Case)** | `Yesterday...` / `Last week...` |
| **后果 (Consequences)** | `Unless we..., we will...` |

## 七、做题 SOP

1. **定位**：题干带引号的句子（如 "Why can't you be more like Amazon?"）会原样出现，答案在其前后
2. **读选项**：理解每个选项，注意 paraphrase，不会原词复现
3. **关键词同义替换**：
   - fixing → adjusting / improving
   - colors; icons → UI details
   - middle part → the process
   - carrier → provider
   - dashboard → platform
   - switch to → leave for / turn to
   - competitors → other platforms / other providers
4. **初听**：听定位词、关键词
5. **再听**：分析比喻、举例、后果，确认 main idea

## 八、听力答案与解析

**背景**：物流跟踪项目（Logistics tracking project）只显示 Shipped 和 Delivered，中间节点缺失。

**角色**：Annie (PM)、Leo (Logistics OPS)、Ming (Tech Lead)、Sarah (Merchant Rep)

**答案**：**B C C**

| 题号 | 答案 | 解析 |
|------|------|------|
| 第一题 | B | dashboard 缺少物流过程中间部分。比喻 "mystery novel where the middle fifty pages have been ripped out" 是为了说明这一点，不是选比喻本身 |
| 第二题 | C | 数据存在，但形式原始、不实时。Ming 先说数据 "doesn't exist"，Leo 用 "Wait a minute" 质疑，Ming 澄清是 "not automatically"、"not in real time" |
| 第三题 | C | 需要先实现数据自动化处理。定位句：*What I am saying is that we need to automate the data processing*；也可从 `Unless we automate the data standards first` 推出 |

## 九、重要表达积累

| 表达 | 含义 |
|------|------|
| monitor user feedback | 持续关注、跟踪用户反馈 |
| track/cancel orders | 跟踪/取消订单 |
| go up by over 50% | 增长超过 50% |
| rip out | 撕掉；彻底移除 |
| let alone | 更不用说……（can't even A, let alone B） |
| top-to-bottom upgrade | 彻底的、全面的升级 |
| stop...from... | 阻止……做某事 |
| rather than | 而不是…… |
| To give you an idea of... | 为了让你了解……（引出例子） |
| What I'm saying is that... | 我的意思是……（澄清观点） |

### 表达痛点的句式

- *One common issue is that...*
- *That's definitely not enough.*
- *Actually, this issue has also caused some trouble...*

### 澄清与确认的句式

- *Wait a minute...*
- *So...Are we talking about...?*
- *What I am saying is that...rather than...*
- *What we actually need is...*
